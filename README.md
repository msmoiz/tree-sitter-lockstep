# Tree Sitter: Lockstep

This repository contains a Tree Sitter grammar for the Lockstep language. It is
logically part of the [Lockstep framework](https://github.com/msmoiz/lockstep),
but it exists as a standalone repository because Zed extensions can only load
grammars from standalone repositories, so pointing the extension at a
subdirectory of the main Lockstep repo fails.
